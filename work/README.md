# work/ — área de trabalho compartilhada

> Scratch entre sessões/agentes. Não é documentação final; é onde findings e progress vivem até virarem `docs/` ou `plans/`.

- `findings.md` — descobertas por investigação (URLs reais, layout, probes)
- `progress.md` — log cronológico por sessão
- `.tmp/` — arquivos temporários (CSVs de teste, outputs DuckDB, etc.) — pode ser apagado
- `plans/` não fica aqui; fica em `../plans/`

## Regra
- Antes de começar fase nova: preencher `findings.md`.
- Ao fechar fase: atualizar `progress.md` e o `task_plan.md` do plan ativo.
